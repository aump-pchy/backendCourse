Week 1

Hello, My First API!

ตอนเรียน Front-End ด้วย Vue เราเป็นฝ่ายขอข้อมูลจาก API ของคนอื่น สัปดาห์นี้เราสลับมาเป็นฝ่ายสร้าง API ที่ตอบข้อมูลอุปกรณ์ของระบบยืมคืน

ทำงานนี้แล้วจะได้อะไร

  • เข้าใจว่าเว็บหรือแอปคุยกับ Server ผ่าน Request และ Response อย่างไร
  • มี Server ของตัวเองที่รันบนเครื่องและตอบข้อมูลเป็น JSON ได้
  • ทดสอบ API ด้วย Thunder Client ได้โดยไม่ต้องมีหน้าเว็บ
  • มี Repository บน GitHub ที่จะต่อยอดเป็นระบบยืมคืนอุปกรณ์ทั้งเทอม

1. API คืออะไร

API (Application Programming Interface) คือช่องทางที่โปรแกรมหนึ่งใช้ขอข้อมูลหรือสั่งงานอีกโปรแกรมหนึ่ง เหมือนเคาน์เตอร์ยืมอุปกรณ์ เราไม่ต้องเดินเข้าห้องเก็บของเอง แค่บอกเจ้าหน้าที่ว่าต้องการอะไร แล้วรอรับของ

กดถัดไปทีละขั้น

Clientผู้ขอข้อมูล
Requestคำขอ
Serverผู้ประมวลผล
Responseคำตอบ

คำความหมายตัวอย่างในวิชานี้
Clientโปรแกรมที่ส่งคำขอเบราว์เซอร์, Thunder Client, หน้าเว็บ Vue
Serverโปรแกรมที่รอรับคำขอแล้วตอบกลับExpress ที่รันบนเครื่องเรา
Endpointที่อยู่ของบริการแต่ละอย่างGET /api/equipment
JSONรูปแบบข้อมูลที่ Client และ Server ใช้รับส่งกัน{"status":"ok"}

ส่วนประกอบของ URL

http://localhost:3000/api/equipment/count แยกได้เป็น 4 ส่วน

เครื่องlocalhostเครื่องที่รัน Server
พอร์ต:3000ช่องที่ Server รอฟัง
พาธ/api/equipment/countบริการที่ต้องการ

localhost หมายถึงเครื่องของเราเอง ส่วนพอร์ต 3000 คือช่องที่ Server รอฟังอยู่ ทุก Endpoint ที่เป็นข้อมูลในวิชานี้ขึ้นต้นด้วย /api เพื่อแยกจากหน้าแรก /

2. Node.js กับ Express

Node.js ทำให้ JavaScript ที่เราใช้ใน Vue รันนอกเบราว์เซอร์ได้ เราจึงใช้ภาษาเดียวกันเขียนได้ทั้ง Front-End และ Back-End

Express คือ library บน Node.js ที่ช่วยสร้าง Server ด้วยโค้ดไม่กี่บรรทัด เราบอก Express ว่า "ถ้ามี Request แบบนี้ ให้ตอบแบบนี้" เรียกว่าการสร้าง Route

รูปแบบของ Route
app.get('/api/health', (req, res) => {
  res.json({ status: 'ok' });
});
// app.get     = รับ Request แบบ GET
// '/api/health' = พาธที่ต้องการ
// req         = ข้อมูลที่ Client ส่งมา
// res         = ใช้ส่งคำตอบกลับ

  • ใช้ Thunder Client ส่ง Request ไปที่ Express ข้อใดถูก

  1. สร้างโฟลเดอร์และเปิดใน VS Codeสร้างโฟลเดอร์ชื่อ equipment-api แล้วเปิดด้วย File → Open Folder โปรเจกต์นี้ใช้ต่อทั้งเทอม

    Terminal

  3. ติดตั้ง Express
    Terminal
    npm install express
    จะได้โฟลเดอร์ node_modules ที่เก็บโค้ดของ Express และไฟล์ package-lock.json
  4. แก้ package.jsonเพิ่ม "type": "module" เพื่อให้ใช้ import ได้ และเพิ่มคำสั่ง start กับ dev
    package.json
    {
  "name": "equipment-api",
  "version": "1.0.0",
  "main": "server.js",
  "type": "module",
  "scripts": {
    "start": "node server.js",
    "dev": "node --watch server.js"
  },
  "dependencies": {
    "express": "^5.1.0"
  }
}
    เลขเวอร์ชันของ Express ในเครื่องอาจต่างได้ ขอให้ขึ้นต้นด้วย 5 ไม่ต้องแก้ตาม

ทำไมต้อง "type": "module"

วิชานี้เขียนแบบ ES Modules คือใช้ import express from 'express' แบบเดียวกับใน Vue ถ้าไม่ใส่บรรทัดนี้ Node.js จะเข้าใจว่าเป็นแบบเก่าที่ใช้ require แล้วแจ้ง error ห้ามแก้ไปใช้ require แทน

5. server.js และ GET API

สร้างไฟล์ server.js ในโฟลเดอร์โปรเจกต์ เริ่มจาก Server ที่ตอบหน้าแรกก่อน

server.js
import express from 'express';

const app = express();
const PORT = 3000;

app.get('/', (req, res) => {
  res.send('Hello, Backend!');
});

app.listen(PORT, () => {
  console.log(`Server running at http://localhost:${PORT}`);
});

รัน Server ด้วยคำสั่ง

Terminal
npm run dev

ผลที่คาดหวัง: Terminal ขึ้น Server running at http://localhost:3000 และค้างไว้แบบนั้น แปลว่า Server กำลังรอ Request อยู่ เปิดเบราว์เซอร์ไปที่ http://localhost:3000 ต้องเห็น Hello, Backend!

เฉาก๊วยบอก

npm run dev ใช้ node --watch บันทึกไฟล์เมื่อไหร่ Server รีสตาร์ตเอง ไม่ต้องหยุดแล้วรันใหม่ ถ้าจะหยุด Server ให้คลิกที่ Terminal แล้วกด Ctrl + C

res.send() กับ res.json()

res.send()res.json()
ส่งอะไรข้อความหรือ HTMLObject หรือ Array ในรูปแบบ JSON
Content-Typetext/htmlapplication/json
ใช้เมื่อหน้าแรก / ที่บอกว่า Server ทำงานทุก Endpoint ใน /api ที่ Client จะนำข้อมูลไปใช้

Content-Type บอก Client ว่าข้อมูลที่ได้เป็นชนิดไหน ถ้าเป็น application/json หน้าเว็บ Vue จะแปลงเป็น Object ไปใช้ต่อได้ทันที

Workshop: Equipment Counter

เพิ่มข้อมูลอุปกรณ์และ Endpoint อีก 3 ตัว ข้อมูลยังเก็บใน Array ในหน่วยความจำ ไปจนถึง Week 3

server.js (ฉบับเต็ม)
import express from 'express';

const app = express();
const PORT = 3000;

const equipment = [
  { id: 101, name: 'Notebook', category: 'computer', quantity: 5 },
  { id: 102, name: 'Projector', category: 'display', quantity: 2 },
  { id: 103, name: 'PC', category: 'computer', quantity: 10 }
];

app.get('/', (req, res) => {
  res.send('Hello, Backend!');
});

app.get('/api/health', (req, res) => {
  res.json({ status: 'ok' });
});

app.get('/api/equipment', (req, res) => {
  res.json(equipment);
});

app.get('/api/equipment/count', (req, res) => {
  res.json({ total: equipment.length });
});

app.listen(PORT, () => {
  console.log(`Server running at http://localhost:${PORT}`);
});

length นับจำนวนรายการ ไม่ใช่ผลรวม quantity

Array นี้มี 3 รายการ equipment.length จึงเป็น 3 แม้ quantity รวมกันจะได้ 5 + 2 + 10 = 17 ก็ตาม /api/equipment/count ตอบว่ามีอุปกรณ์กี่ ประเภท ในระบบ ไม่ใช่กี่ ชิ้น

MethodEndpointผลลัพธ์
GET/Hello, Backend!
GET/api/health{"status":"ok"}
GET/api/equipmentArray อุปกรณ์ 3 รายการ
GET/api/equipment/count{"total":3}

6. Git และ GitHub

Git บันทึกประวัติการแก้โค้ดเป็นจุด ๆ เรียกว่า commit ถ้าวันหนึ่งโค้ดพังก็ย้อนกลับได้ ส่วน GitHub คือที่เก็บ Repository บนอินเทอร์เน็ต ครูตรวจงานจากที่นี่ ทุกคนใช้ Repository ของตัวเอง 1 อัน ต่อยอดทั้งเทอม

สร้าง .gitignore ก่อน commit ครั้งแรก

สร้างไฟล์ชื่อ .gitignore (มีจุดข้างหน้า) ในโฟลเดอร์โปรเจกต์ บอก Git ว่าไม่ต้องเก็บไฟล์เหล่านี้

.gitignore
node_modules/
.env
.DS_Store

node_modules มีไฟล์เป็นพันไฟล์และสร้างใหม่ได้ด้วย npm install ส่วน .env ใช้เก็บรหัสผ่านในสัปดาห์หลัง ๆ ห้ามขึ้น GitHub เด็ดขาด

แก้ปัญหาที่พบบ่อย

Windows ขึ้น npm.ps1 cannot be loaded because running scripts is disabled

PowerShell บล็อกการรันสคริปต์ ให้เปลี่ยน Terminal ใน VS Code เป็น Command Prompt: กดลูกศรข้างปุ่ม + ของ Terminal → Select Default Profile → Command Prompt แล้วเปิด Terminal ใหม่

'node' is not recognized หรือ command not found: node

ยังไม่ได้ติดตั้ง Node.js หรือยังไม่ได้เปิด VS Code ใหม่หลังติดตั้ง ให้ปิด VS Code ทั้งหมดแล้วเปิดใหม่ ถ้ายังไม่ได้ให้ติดตั้ง Node.js อีกครั้ง

Cannot use import statement outside a module

ยังไม่ได้ใส่ "type": "module" ใน package.json หรือใส่ผิดตำแหน่ง ต้องอยู่ในวงเล็บปีกกาชั้นนอกสุด และมีจุลภาคคั่นกับบรรทัดก่อนหน้า

Error: listen EADDRINUSE: address already in use :::3000

มี Server ตัวเก่ารันค้างอยู่ในอีก Terminal ให้หา Terminal นั้นแล้วกด Ctrl + C หรือกดไอคอนถังขยะเพื่อปิด Terminal ทั้งหมด แล้วรันใหม่

Thunder Client ขึ้น Connection was refused

Server ไม่ได้รันอยู่ ดูใน Terminal ว่ามี error หรือถูกหยุดไปหรือไม่ แล้วรัน npm run dev ใหม่

ได้ Cannot GET /api/... ทั้งที่เขียน Route แล้ว

พาธใน Thunder Client กับในโค้ดต้องตรงกันทุกตัวอักษร เช่น equipment ไม่มี s และขึ้นต้นด้วย /api ตรวจว่าบันทึกไฟล์แล้ว (ไม่มีจุดกลมบนแท็บไฟล์)

เผลอ push node_modules ขึ้น GitHub ไปแล้ว

สร้าง .gitignore ให้ถูกก่อน แล้วสั่งให้ Git เลิกติดตามโฟลเดอร์นั้น โดยไฟล์ในเครื่องยังอยู่

git rm -r --cached node_modules
git commit -m "remove node_modules"
git push

Exit Ticket

ทำก่อนออกจากคาบ ตอบด้วยคำพูดของตัวเองสั้น ๆ แล้วกดสรุปเพื่อคัดลอกส่งครู

1. API ช่วยให้ Client และ Server ติดต่อกันอย่างไร?

แนวคำตอบ: Client ส่ง Request ที่มี Method และ URL ไปยัง Endpoint ของ Server แล้ว Server ประมวลผลและส่ง Response ที่มี Status และข้อมูลกลับมา

2. res.send() กับ res.json() ต่างกันอย่างไร?

แนวคำตอบ: res.send() ส่งข้อความหรือ HTML ส่วน res.json() แปลง Object หรือ Array เป็น JSON และตั้ง Content-Type เป็น application/json ให้ Client นำไปใช้ต่อได้

3. ถ้ามี 3 รายการ แต่ quantity รวม 17 ค่า equipment.length คือเท่าไร เพราะเหตุใด?

แนวคำตอบ: ได้ 3 เพราะ length นับจำนวนสมาชิกใน Array ไม่ได้รวมค่า quantity ของแต่ละรายการ

มั่นใจแค่ไหนว่าทำ JOB.01 เองได้ (1 = ยังไม่ได้เลย, 5 = สอนเพื่อนได้)
