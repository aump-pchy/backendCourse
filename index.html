สร้าง API ของตัวเอง ทีละ Endpoint

เทอมนี้ทุกคนสร้างระบบยืมคืนอุปกรณ์ด้วย Node.js และ Express ใน Repository ของตัวเอง อ่านแล้วทำตามได้เองทีละขั้น ทดสอบด้วย Thunder Client แล้วทำ Exit Ticket ก่อนออกจากคาบ

เริ่ม Week 1

บทเรียน

  1. Week1

    Hello, My First API!

    API คืออะไร, เตรียมเครื่อง, สร้าง Server ด้วย Express, GET API แรก, Git และ GitHub

    ตรวจผลแล้ว 0/8ยังไม่ทำ Exit Ticket
  2. Week2

    Building Smarter APIs

    Status Code, Query และ Path Parameter, ค้นหาด้วย ID, เพิ่มอุปกรณ์ด้วย POST และ Validation

    ตรวจผลแล้ว 0/9ยังไม่ทำ Exit Ticket
  3. Week3

    Update & Delete

    แก้บางฟิลด์ด้วย PATCH, ลบด้วย DELETE, ตรวจข้อมูลก่อนเปลี่ยน และ API Test Challenge

    ตรวจผลแล้ว 0/8ยังไม่ทำ Exit Ticket
  4. Week4

    เริ่มต้น MySQL

    ติดตั้ง MySQL Server และใช้งาน MySQL CLI โดยไม่ใช้ XAMPP สร้างฐานข้อมูลและตาราง

    เร็ว ๆ นี้

  2. ขั้นที่ 2สร้างฐานข้อมูล ตาราง และฝึก SQL

AI ช่วยได้

อธิบายโค้ดที่ยังไม่เข้าใจ อ่าน error ให้ ช่วยคิดกรณีทดสอบ ร่างโค้ดตัวอย่าง

เราต้องทำเอง

อ่านและอธิบายทุกบรรทัดที่ส่งได้ รันและทดสอบจริงด้วย Thunder Client ตรวจว่าตรงเงื่อนไขของงาน

ถ้าครูถามว่าบรรทัดนี้ทำอะไร แล้วตอบไม่ได้ ถือว่างานส่วนนั้นยังไม่ผ่าน

สัปดาห์ที่ครูไม่อยู่

บางคาบครูมีภารกิจ ให้เปิดบทเรียนของสัปดาห์นั้นแล้วทำตามลำดับ เป้าหมาย → แนวคิด → ลงมือเขียน → ทดสอบ → ตรวจผล → ลองเอง → ส่งงาน ถ้างานสัปดาห์ก่อนยังไม่ผ่าน ให้กลับไปทำให้เรียบร้อยก่อนเริ่มบทใหม่ ติดตรงไหนให้จดไว้ในข้อ "ยังสงสัยตรงไหน" ของ Exit Ticket

แผนกวิชาเทคโนโลยีสารสนเทศ วิทยาลัยเทคนิคเลย

ความคืบหน้าและสถานะ Exit Ticket บันทึกไว้ในเบราว์เซอร์เครื่องนี้เท่านั้น
